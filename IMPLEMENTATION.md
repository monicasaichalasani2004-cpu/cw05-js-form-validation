# CW-05 Implementation Notes

Course: CSC 6370 - Web Programming

The project uses:
- HTML for form structure
- CSS for layout and validation styling
- JavaScript for input validation
- Arrays and loops for collecting errors
- DOM events for handling form submissions
- ARIA attributes for accessible error feedback

innerHTML is used for predefined messages.
textContent is used for user input to reduce XSS risks.
